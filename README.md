🛍️ COZA E-Commerce Website

A simple e-commerce website built with HTML,JavaScript, and Tailwind CSS.

📄 Pages:

index.html - Homepage
shop.html - Shop page
product.html - Product details page
script.js - JavaScript file


✨ What it does:

- Shows products from an API
- You can search and filter products
- Click on a product to see its details
- Works on mobile and desktop
